Give a new teammate a concise tour of this repository. Focus area (optional): $ARGUMENTS

Use the `project-context` skill, then answer:

1. **What it is**: the purpose of the project in two sentences.
2. **How to run it**: install, run, test and lint commands (from `AGENTS.md`), and any setup gotchas you find.
3. **Map**: the main folders and what lives in each.
4. **Key flows**: the two or three most important code paths, with file references.
5. **Where to start**: a good first file to read and a small, safe first task.

Keep it under one screen. Link files as `path:line` where it helps.
